% macros-defaults.tex -- The Unmeasured Remainder (paper 2)
%
% The contract between main.tex and the generator script
% (scripts/players/make_paper2.py, run by `make paper2`). Every number that
% comes from data, and every data-derived name, is one of the macros below.
% main.tex inputs this file first, then generated/macros.tex if it exists.
%
% Rules for the generator:
% - Redefine with \renewcommand{\Name}{value}. Never \newcommand (the names
%   already exist) and never a name not declared here.
% - Values are set in running text, never in math mode. Write a negative
%   number as $-0.05$ (or \textminus), a share as a decimal unless the comment
%   says "percent", and an interval bound as a bare number.
% - "results/players/<dir>/" names the output directory of the module; the
%   file inside it is the generator's choice, as long as the value is read
%   from a file a run wrote, never typed.
% - Shares are in [0, 1] unless the comment says "raw" (may lie outside).
% - 90% intervals throughout (pre-registration), unless stated.
%
% Defaults render as [pending] (\TBD, defined in main.tex), so the draft
% compiles before any result exists.
